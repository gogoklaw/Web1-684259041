SECTION 01

Introduction to HTML


What is HTML?

HTML ย่อมาจาก Hyper Text Markup Language เป็นภาษามาร์กอัปมาตรฐานที่ใช้สำหรับ สร้างและกำหนดโครงสร้างของเว็บเพจ


HTML ช่วยให้เราสามารถกำหนดส่วนต่าง ๆ ของเว็บไซต์ เช่น หัวข้อ ข้อความ รูปภาพ ลิงก์ ตาราง และแบบฟอร์มได้



How HTML Works & HTML Elements

HTML ใช้ Elements และ Tags เพื่อบอก Web Browser ว่าเนื้อหาแต่ละส่วนคืออะไร และควรแสดงผลอย่างไร

ตัวอย่าง:

<h1>Hello World!</h1>

<p>Welcome to my website.</p>

ในตัวอย่างนี้

  • <h1> ใช้สำหรับสร้าง Heading
  • <p> ใช้สำหรับสร้าง Paragraph
  • Browser จะอ่าน Tags แล้วแสดงผลออกมาเป็นหน้าเว็บ
  • Tags จะไม่แสดงให้ผู้ใช้เห็นโดยตรง แต่จะกำหนดว่าเนื้อหานั้นควรแสดงผลอย่างไร

HTML Element คือส่วนประกอบต่าง ๆ ของหน้าเว็บ โดยทั่วไปประกอบด้วย Opening Tag + Content + Closing Tag

SECTION 02

HTML Document Structure


Basic Structure of HTML

HTML Document จะมีโครงสร้างพื้นฐานที่ช่วยให้ Web Browser เข้าใจว่าแต่ละส่วนของเว็บไซต์ทำหน้าที่อะไร

<!DOCTYPE html>

<html>

  <head>

    <title>My Website</title>

  </head>

  <body>

    <h1>Hello World!</h1>

  </body>

</html>

โครงสร้างแต่ละส่วนมีหน้าที่ดังนี้

  • <!DOCTYPE html> ใช้ระบุว่าเอกสารนี้เป็น HTML5
  • <html> เป็นรากของเอกสาร HTML ทั้งหมด
  • <head> ใช้เก็บข้อมูลของหน้าเว็บ เช่น <title>
  • <body> เป็นส่วนที่แสดงเนื้อหาบนหน้าเว็บ


HTML Tags

HTML Tags คือส่วนที่ใช้กำหนดว่าเนื้อหาแต่ละส่วนคืออะไร โดยทั่วไปจะมี Opening Tag และ Closing Tag

<h1>Hello, World!</h1>

ในตัวอย่างนี้

  • <h1> คือ Opening Tag
  • Hello, World! คือ Content
  • </h1> คือ Closing Tag


HTML Attributes

Attributes คือคุณสมบัติเพิ่มเติมของ HTML Tag ใช้สำหรับกำหนดรายละเอียดหรือพฤติกรรมเพิ่มเติมให้กับ Element

<img src="image.jpg" alt="A description of the image">

ตัวอย่าง Attributes ที่พบได้บ่อย

  • href ใช้กำหนด URL ของ Link
  • src ใช้กำหนดตำแหน่งของไฟล์
  • width ใช้กำหนดความกว้าง
  • height ใช้กำหนดความสูง

SECTION 03

Heading


What is Heading?

Heading คือส่วนที่ใช้สำหรับกำหนดหัวข้อของเนื้อหาในหน้าเว็บ โดย HTML มี Heading ตั้งแต่ <h1> ถึง <h6>



Heading Levels

HTML มี Heading ทั้งหมด 6 ระดับ โดยแต่ละระดับจะมีความสำคัญ และขนาดที่แตกต่างกัน

<h1>Heading 1</h1>

<h2>Heading 2</h2>

<h3>Heading 3</h3>

<h4>Heading 4</h4>

<h5>Heading 5</h5>

<h6>Heading 6</h6>

Heading แต่ละระดับ

  • <h1> ใช้สำหรับ Heading 1
  • <h2> ใช้สำหรับ Heading 2
  • <h3> ใช้สำหรับ Heading 3
  • <h4> ใช้สำหรับ Heading 4
  • <h5> ใช้สำหรับ Heading 5
  • <h6> ใช้สำหรับ Heading 6


Example

เราสามารถใช้ Heading เพื่อแบ่งหัวข้อและจัดลำดับเนื้อหา ให้ Web Browser และผู้ใช้อ่านได้ง่ายขึ้น

<h1>My Website</h1>

<h2>About Me</h2>

<h3>My Skills</h3>

SECTION 04

Paragraph


What is Paragraph?

Paragraph คือส่วนที่ใช้สำหรับแสดงข้อความหรือเนื้อหาเป็นย่อหน้า โดย HTML จะใช้ <p> Tag สำหรับสร้าง Paragraph



How to Create a Paragraph

เราสามารถสร้าง Paragraph ได้โดยใส่ข้อความไว้ระหว่าง Opening Tag และ Closing Tag ของ <p>

<p>Hello World!</p>

<p>Welcome to my website.</p>

ในตัวอย่างนี้

  • <p> คือ Opening Tag
  • Hello World! คือ Content
  • </p> คือ Closing Tag
  • แต่ละ <p> จะใช้สำหรับสร้างข้อความหนึ่ง Paragraph


Multiple Paragraphs

เราสามารถสร้างหลาย Paragraph ในหน้าเว็บได้ โดยแต่ละ Paragraph จะถูกเขียนแยกออกจากกัน

<p>This is the first paragraph.</p>

<p>This is the second paragraph.</p>

การใช้ Paragraph ช่วยให้เนื้อหาบนเว็บไซต์เป็นระเบียบ และทำให้ผู้ใช้อ่านเนื้อหาได้ง่ายขึ้น

SECTION 05

Text Formatting


What is Text Formatting?

Text Formatting คือการจัดรูปแบบข้อความใน HTML เพื่อทำให้ข้อความมีลักษณะหรือความหมายที่แตกต่างกัน เช่น ตัวหนา ตัวเอียง ขีดเส้นใต้ หรือการเน้นข้อความ



Basic Text Formatting

HTML มี Tag หลายรูปแบบสำหรับจัดการข้อความ โดยแต่ละ Tag จะมีหน้าที่แตกต่างกัน

<b>Bold Text</b>

<i>Italic Text</i>

<u>Underline Text</u>

<mark>Highlighted Text</mark>

ในตัวอย่างนี้

  • <b> ใช้สำหรับทำข้อความตัวหนา
  • <i> ใช้สำหรับทำข้อความตัวเอียง
  • <u> ใช้สำหรับขีดเส้นใต้ข้อความ
  • <mark> ใช้สำหรับเน้นหรือ Highlight ข้อความ


Strong and Emphasized Text

นอกจากการจัดรูปแบบข้อความทั่วไปแล้ว HTML ยังมี <strong> และ <em> สำหรับเน้นความสำคัญของข้อความ

<strong>Important Text</strong>

<em>Emphasized Text</em>

การใช้ Text Formatting ช่วยให้เนื้อหาบนเว็บไซต์ อ่านง่ายขึ้นและสามารถเน้นข้อความที่สำคัญให้ผู้ใช้สังเกตได้ง่าย

SECTION 06

Creating Links


What is a Link?

Link หรือ Hyperlink คือการสร้างลิงก์สำหรับเชื่อมโยงไปยังหน้าเว็บ ไฟล์ หรือส่วนต่าง ๆ ของหน้าเว็บ


HTML ใช้ <a> หรือ Anchor Tag สำหรับสร้างลิงก์ โดยกำหนดปลายทางของลิงก์ผ่าน href

ตัวอย่าง:

<a href="https://example.com">Visit Website</a>

ในตัวอย่างนี้

  • <a> ใช้สำหรับสร้าง Link
  • href ใช้กำหนด URL หรือปลายทางของ Link
  • ข้อความที่อยู่ระหว่าง <a> และ </a> คือข้อความที่ผู้ใช้มองเห็นและคลิกได้


href Attribute

href หรือ Hypertext Reference ใช้สำหรับกำหนด URL ของหน้าเว็บหรือไฟล์ที่ต้องการเชื่อมโยงไป

ตัวอย่าง:

<a href="about.html">About Us</a>


target Attribute

target ใช้กำหนดว่า Link จะเปิดหน้าเว็บในตำแหน่งใด เช่น เปิดในหน้าต่างเดิม หรือเปิด Tab ใหม่

<a href="page.html" target="_self">Open Page</a>

<a href="page.html" target="_blank">Open New Tab</a>

ค่า target ที่ใช้บ่อย

  • _self เปิดหน้าเว็บในหน้าต่างหรือ Tab เดิม
  • _blank เปิดหน้าเว็บในหน้าต่างหรือ Tab ใหม่
  • _parent เปิดหน้าเว็บใน Parent Frame
  • _top เปิดหน้าเว็บใน Full Body ของหน้าต่าง


Anchor Links

Anchor Link ใช้สำหรับสร้าง Link ที่สามารถพาผู้ใช้ไปยัง ส่วนใดส่วนหนึ่งของหน้าเว็บเดียวกัน

สามารถใช้ # ร่วมกับ id เพื่อระบุตำแหน่งที่ต้องการให้ Link เลื่อนไปหา

ตัวอย่าง:

<a href="#section">Go to Section</a>

<h3 id="section">This is the Section</h3>


Email Links

สามารถสร้าง Link สำหรับเปิดโปรแกรม Email โดยใช้ mailto: นำหน้าที่อยู่ Email

ตัวอย่าง:

<a href="mailto:support@example.com">Email Us</a>


Download Links

สามารถสร้าง Link สำหรับดาวน์โหลดไฟล์ได้โดยใช้ download Attribute

ตัวอย่าง:

<a href="file.txt" download>Download Text File</a>



สรุป

  • <a> ใช้สำหรับสร้าง Link
  • href ใช้กำหนดปลายทางของ Link
  • target ใช้กำหนดตำแหน่งที่ Link จะเปิด
  • # และ id ใช้สร้าง Anchor Link ภายในหน้าเว็บ
  • mailto: ใช้สร้าง Email Link
  • download ใช้สร้าง Download Link

SECTION 07

Lists (Ordered and Unordered)


What is a List?

List คือการจัดข้อมูลให้อยู่ในรูปแบบรายการ ซึ่ง HTML มี List หลัก ๆ อยู่ 2 ประเภท คือ Unordered List และ Ordered List


Unordered List

Unordered List คือรายการที่ไม่มีลำดับตัวเลข โดยใช้ <ul> หรือ Unordered List และใช้ <li> สำหรับสร้างแต่ละรายการ

ตัวอย่าง:

<ul>

    <li>Coffee</li>

    <li>Tea</li>

    <li>Milk</li>

</ul>

ในตัวอย่างนี้

  • <ul> ใช้สำหรับสร้าง Unordered List
  • <li> ใช้สำหรับสร้าง List Item
  • รายการจะแสดงด้วยสัญลักษณ์หน้าข้อความ เช่น Bullet


Ordered List

Ordered List คือรายการที่มีลำดับ เช่น 1, 2, 3 โดยใช้ <ol> หรือ Ordered List และใช้ <li> สำหรับสร้างแต่ละรายการ

ตัวอย่าง:

<ol>

    <li>Coffee</li>

    <li>Tea</li>

    <li>Milk</li>

</ol>


List Style Types

สามารถกำหนดรูปแบบของ List ได้โดยใช้ list-style-type Property

ตัวอย่างของ Unordered List:

<ul style="list-style-type: disc;">

<ul style="list-style-type: circle;">

<ul style="list-style-type: square;">

<ul style="list-style-type: none;">


ตัวอย่างของ Ordered List:

<ol type="1">

<ol type="A">

<ol type="a">

<ol type="I">

<ol type="i">

รูปแบบของ Ordered List

  • 1 ใช้ตัวเลข เช่น 1, 2, 3
  • A ใช้ตัวอักษรภาษาอังกฤษตัวพิมพ์ใหญ่
  • a ใช้ตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก
  • I ใช้เลขโรมันตัวพิมพ์ใหญ่
  • i ใช้เลขโรมันตัวพิมพ์เล็ก


สรุป

  • <ul> ใช้สร้าง Unordered List
  • <ol> ใช้สร้าง Ordered List
  • <li> ใช้สร้าง List Item
  • list-style-type ใช้กำหนดรูปแบบของ List

SECTION 08

Adding Images


What is an Image?

Image คือรูปภาพที่สามารถนำมาแสดงบน Web Page ได้ โดย HTML ใช้ <img> Tag สำหรับเพิ่มรูปภาพลงในหน้าเว็บ


การแสดงรูปภาพจำเป็นต้องกำหนดตำแหน่งของไฟล์ผ่าน src และสามารถกำหนดคำอธิบายรูปภาพผ่าน alt ได้

ตัวอย่าง:

<img src="image.jpg" alt="A description of the image">

ในตัวอย่างนี้

  • <img> ใช้สำหรับแสดงรูปภาพ
  • src ใช้กำหนดตำแหน่งหรือ Path ของรูปภาพ
  • alt ใช้กำหนดข้อความอธิบายรูปภาพ


Image Size

สามารถกำหนดขนาดของรูปภาพได้โดยใช้ width และ height Attribute

ตัวอย่าง:

<img src="image.jpg" alt="Image" width="300" height="200">


Image Alignment

สามารถกำหนดตำแหน่งของรูปภาพได้โดยใช้ align Attribute

ตัวอย่าง:

<img src="image.jpg" alt="Image" align="right">



Image Border

สามารถเพิ่มเส้นขอบให้กับรูปภาพได้โดยใช้ border Attribute

ตัวอย่าง:

<img src="image.jpg" alt="Image" border="2">


Image as a Link

สามารถทำให้รูปภาพสามารถคลิกเพื่อไปยังหน้าอื่นได้ โดยนำ <img> ไปไว้ภายใน <a> Tag

ตัวอย่าง:

<a href="index.html">

    <img src="image.jpg" alt="Home">

</a>



Image Gallery

สามารถสร้าง Image Gallery โดยนำรูปภาพหลายรูปมาแสดงรวมกันภายในหน้าเว็บ

ตัวอย่าง:

<div class="gallery">

    <img src="image1.jpg" alt="Image 1">

    <img src="image2.jpg" alt="Image 2">

    <img src="image3.jpg" alt="Image 3">

</div>


Using Flexbox with Images

สามารถใช้ CSS Flexbox เพื่อจัดตำแหน่งรูปภาพหลายรูปให้อยู่ในรูปแบบที่ต้องการได้

ตัวอย่าง:

.gallery {

    display: flex;

    gap: 10px;

}



สรุป

  • <img> ใช้สำหรับแสดงรูปภาพ
  • src ใช้กำหนดตำแหน่งของรูปภาพ
  • alt ใช้กำหนดคำอธิบายรูปภาพ
  • width และ height ใช้กำหนดขนาดรูปภาพ
  • align ใช้กำหนดตำแหน่งของรูปภาพ
  • border ใช้กำหนดเส้นขอบของรูปภาพ
  • สามารถใช้ Image ร่วมกับ Link และ CSS Flexbox ได้

SECTION 09

Creating Tables


What is an HTML Table?

HTML Table คือการจัดข้อมูลให้อยู่ในรูปแบบตาราง โดยสามารถแบ่งข้อมูลออกเป็นแถวและคอลัมน์ เพื่อให้ข้อมูลสามารถอ่านและเปรียบเทียบได้ง่ายขึ้น


HTML ใช้ <table>, <tr>, <th> และ <td> Tag สำหรับสร้างและกำหนดโครงสร้างของตาราง

ตัวอย่าง:

<table>

    <tr>

        <th>Name</th>

        <th>Age</th>

    </tr>

    <tr>

        <td>Tee</td>

        <td>19</td>

    </tr>

</table>

ในตัวอย่างนี้

  • <table> ใช้สำหรับสร้าง Table
  • <tr> ใช้สำหรับสร้าง Table Row หรือแถวของตาราง
  • <th> ใช้สำหรับสร้าง Table Header หรือหัวตาราง
  • <td> ใช้สำหรับสร้าง Table Data หรือข้อมูลภายในเซลล์


Table Structure

โครงสร้างพื้นฐานของ HTML Table จะประกอบด้วย Table, Row, Header และ Data โดยสามารถนำแต่ละส่วนมาประกอบกันเพื่อสร้างตารางได้

โครงสร้างหลัก:

<table>

    <tr>

        <th>Header</th>

    </tr>

    <tr>

        <td>Data</td>

    </tr>

</table>



Table Tags

Tag ที่ใช้ในการสร้าง HTML Table มีหน้าที่แตกต่างกันดังนี้

  • <table> : Table
  • <tr> : Table Row
  • <th> : Table Header
  • <td> : Table Data / Cell


สรุป

  • <table> ใช้สร้างตาราง
  • <tr> ใช้สร้างแถวของตาราง
  • <th> ใช้สร้างหัวตาราง
  • <td> ใช้สร้างข้อมูลหรือเซลล์ในตาราง

SECTION 10

HTML Forms


What is an HTML Form?

HTML Form คือส่วนที่ใช้สำหรับรับข้อมูลจากผู้ใช้ เช่น ชื่อ รหัสผ่าน Email ตัวเลข วันที่ หรือไฟล์ แล้วสามารถส่งข้อมูลไปยัง Server เพื่อประมวลผลต่อได้


HTML Forms ถูกสร้างขึ้นด้วย <form> Tag ซึ่งใช้เป็นตัวครอบข้อมูลทั้งหมดที่อยู่ภายใน Form

ตัวอย่าง:

<form action="/submit" method="post">

    <input type="text">

    <input type="submit">

</form>

ในตัวอย่างนี้

  • <form> ใช้เป็นตัวครอบข้อมูลใน Form
  • action ใช้กำหนดปลายทางที่จะส่งข้อมูล
  • method ใช้กำหนดวิธีการส่งข้อมูล เช่น GET หรือ POST


Form Structure

โครงสร้างพื้นฐานของ Form ประกอบด้วย <form>, action และ method

ตัวอย่าง:

<form action="/submit" method="post">

    Form Data

</form>



Input Types

<input> สามารถกำหนดชนิดของข้อมูลที่ต้องการรับได้หลายรูปแบบ เช่น Text, Password, Email, Number, Radio, Checkbox, Date และ File

ตัวอย่าง:

<input type="text">

<input type="password">

<input type="email">

<input type="number">

<input type="radio">

<input type="checkbox">

<input type="date">

<input type="file">


Other Form Elements

นอกจาก <input> แล้ว HTML ยังมี Element อื่น ๆ สำหรับรับข้อมูลจากผู้ใช้

  • <textarea> ใช้สร้างช่องสำหรับกรอกข้อความขนาดใหญ่
  • <select> และ <option> ใช้สร้างเมนูแบบเลื่อนลง
  • <datalist> ใช้สร้างรายการตัวเลือกที่กำหนดไว้ล่วงหน้า
  • <optgroup> ใช้จัดกลุ่มตัวเลือก
  • <fieldset> และ <legend> ใช้จัดกลุ่มข้อมูลที่เกี่ยวข้องกัน


Form Buttons

HTML มีปุ่มหลายประเภทสำหรับใช้งานภายใน Form เช่น ปุ่มส่งข้อมูล ปุ่มล้างข้อมูล และปุ่มทั่วไป

ตัวอย่าง:

<button>Submit</button>

<input type="submit">

<input type="reset">

<input type="button">

ประเภทของปุ่ม

  • <button> ใช้สร้างปุ่มทั่วไป
  • submit ใช้สำหรับส่งข้อมูลใน Form
  • reset ใช้สำหรับล้างข้อมูลใน Form
  • button ใช้สร้างปุ่มทั่วไป
  • image ใช้สร้างปุ่มที่เป็นรูปภาพ
  • file ใช้สร้างปุ่มสำหรับอัปโหลดไฟล์


Form Validation

Form Validation คือการตรวจสอบข้อมูลที่ผู้ใช้กรอก ก่อนที่จะส่งข้อมูลไปยัง Server

HTML มี Attribute ที่ช่วยตรวจสอบข้อมูล เช่น required, min, max และ pattern

ตัวอย่าง:

<input type="text" required>

<input type="number" min="1" max="100">

<input type="text" pattern="[A-Za-z]+">


HTML5 Form Features

HTML5 เพิ่ม Attribute ที่ช่วยให้การสร้าง Form สะดวกและใช้งานง่ายมากขึ้น

  • placeholder ใช้แสดงข้อความแนะนำภายใน Input
  • autofocus ใช้กำหนดให้ Input ถูกเลือกโดยอัตโนมัติเมื่อเปิดหน้าเว็บ
  • สามารถใช้ JavaScript เพื่อช่วยตรวจสอบข้อมูลภายใน Form ได้


Form Submission

เมื่อผู้ใช้กรอกข้อมูลเสร็จแล้ว Form สามารถส่งข้อมูลไปยัง Server เพื่อประมวลผลต่อได้ โดยสามารถใช้ JavaScript เช่น onsubmit เพื่อจัดการเหตุการณ์ตอนส่ง Form

ตัวอย่าง:

<form onsubmit="return validateForm()">

    Form Data

</form>



สรุป

  • <form> ใช้สร้าง Form สำหรับรับข้อมูล
  • action และ method ใช้กำหนดการส่งข้อมูล
  • <input> ใช้รับข้อมูลหลายประเภท
  • <textarea> ใช้รับข้อความขนาดใหญ่
  • <select> และ <option> ใช้สร้าง Dropdown
  • required, min, max และ pattern ใช้สำหรับ Validation
  • สามารถใช้ JavaScript เพื่อจัดการและตรวจสอบ Form ได้
